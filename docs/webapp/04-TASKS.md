### W-005 · Эндпоинт `/me` · DONE
**Критерии приёмки**
- [x] `GET /api/v1/me` отдаёт профиль, активную группу, тариф и лимиты (формат — `03-API.md`)
- [x] Пользователь создаётся при первом входе, как в боте
- [x] `PATCH /api/v1/me` меняет язык
- [x] Лимиты берутся из `SubscriptionLimitsService`, не хардкодятся

**Зависимости:** W-004

**Результат:**
- `MeController` + `MeResponseFactory`. Тариф считается по сроку: истёкший `PAID` отдаётся как `FREE`.
  Безлимит — `null`. `expiresAt` — ISO-8601 UTC.
- Язык в ответе — эффективный: выбранный → `language_code` из Telegram → `ru`.
- Пользователь без групп получает `activeGroupId: null`; личную группу создаёт онбординг бота (решение D-007).
- AI-лимиты перенесены в `SubscriptionLimitsService` — теперь все лимиты тарифа в одном месте;
  `AiRateLimitService` и экран подписки в боте читают их оттуда.
- **Онбординг вынесен в `OnboardingService`.** В боте выбор языка создаёт личную группу, если групп нет,
  а бот показывает выбор языка по признаку `language == null`. Если бы `PATCH /me` только менял язык,
  бот пропустил бы этот шаг и пользователь остался бы без группы. Теперь бот и web вызывают один `selectLanguage`.
  Заодно убран дубль: личная группа создавалась в двух местах, ключ имени был объявлен дважды.
- `PATCH` проверяет язык: не `ru`/`en`/`kk` → `400` с `details.supported`; пустое тело → `400`.
- Тесты: `MeControllerTest` (7, `@WebMvcTest`), `OnboardingServiceTest` (3). Мутации — без проверки языка,
  тариф без учёта срока, безлимит не `null`, онбординг без группы — ловятся.
- Общая настройка web-тестов вынесена: `@ApiWebLayerSetup` и фикстуры в `WebTestFixtures.kt`.
